## The entry

> My cat knocked my coffee off the table, stared at me while it fell, then walked away — honestly, the most honest feedback I have ever received.

(143 characters, single line.)

## What this does

`main.py` prints exactly the entry text to stdout — one line, nothing
else. It validates the text is 1–199 characters, a single line, with
no leading/trailing whitespace and no double spaces before printing.
Python 3, stdlib only, deterministic — no network, no clock, no
randomness.

## How to run

```bash
python3 main.py
```
